Here I summarized serveral key techniques mentioned in the report.

## Long-context efficiency
1. Reusing keys as values in global attention layers (except E2B and E4B), as K = V, cutting the global KV cache reqiured in half.
2. Proportional RoPE (p-RoPE), sliding window attention are allocated base RoPE while full attention are p-RoPE with p = 0.25.

## Encoder-free architecture (12B version only)
Project raw 40ms audio chunks and raw image patches directly into LLM embedding layer. For vision modality, it takes 48x48x3 rgb patch, so they replace the vision encoder to a large 35M matmul. For audio modality, it segment into 40ms x 16kHZ, resulting in 640 dimentional vectors per chunk, project into llm embedding without a postional embedding.

## Per-Layer Embedding on Edge Variants (for E2B and E4B version)
To increase a small model's knowledge without increasing the hidden layer dimention or number of model layers. It reqiures every Transformer layer a small dimention of embedding to achieve more information per token. In this way, the model get more learnable paragrams with the calculate efficiency embedding lookup.
