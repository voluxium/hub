## 代码块

下面是一段示例代码，会被放进黑色圆角框中：

```python
def fibonacci(n: int) -> list[int]:
    """返回前 n 项斐波那契数。"""
    seq = [0, 1]
    for _ in range(n - 2):
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

print(fibonacci(10))
```
